# V17 primary-source research register

Checked October 29, 2026, IST. This is a broad, targeted review of relevant papers, author repositories, model documentation and benchmark-maintainer records. It is not a claim to have checked the entire internet. No public competition predictions, restaurant target matches or external labels were used.

The table separates author-reported capability, measured local history and this plan's inference. Benchmark results are research leads; none measures this competition's hidden targets. Live default branches can change: implementation must pin exact revisions and checkpoint hashes before development.
