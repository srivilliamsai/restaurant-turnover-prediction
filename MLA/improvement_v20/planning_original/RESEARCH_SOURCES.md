# V20 source review

Checked October 29, 2026, IST. Public official pages and local primary artifacts were reviewed. This task performed no training, model-weight downloads, dependency installation, account changes, runtime allocation or portal upload.

## Online primary sources

| Source | Verified evidence | Decision and limit |
|---|---|---|
| [Official TabICL repository](https://github.com/soda-inria/tabicl), [package requirements](https://github.com/soda-inria/tabicl/blob/main/pyproject.toml) | Regression API and the `tabicl-regressor-v2-20260212.ckpt` checkpoint; control over AMP, FA3 and ensemble size; state persistence; base package requirements. | Recheck the original V11 recipe. Published benchmark performance does not establish a gain over the restaurant V14 ensemble. Current docs are not proof that every feature exists in pinned version 2.2.0; execution uses the already-run V11 API and verifies persistence against that installed version. |
| [NVIDIA package repository](https://github.com/NVIDIA/structured-data-models), [package metadata](https://github.com/NVIDIA/structured-data-models/blob/main/pyproject.toml) | PyTorch/Python requirements and optional CUDA dataframe integration. cuDF is recommended, not a mandatory base dependency. | Clean candidate environment is the proposed repair. No claim that a particular Numba pin has been tested. |
| [Kumo API and recipe](https://nvidia.github.io/structured-data-models/api/generated/sdm.models.KumoTabular), [data-processing guide](https://nvidia.github.io/structured-data-models/processing.html) | Explicit Small/Medium/Large selection; default size is Large; regression produces 999 quantiles; fitted recipes transform targets and invert outputs; trimmed estimator aggregation. | Explicit Small with a frozen quantile-grid mean. Underlying numerical core and recipe's categorical adapter are distinct. |
| [Google Research TabFM README](https://github.com/google-research/tabfm/blob/main/README.md), [estimator implementation](https://github.com/google-research/tabfm/blob/main/tabfm/src/classifier_and_regressor.py) | Official regression wrapper and PyTorch/JAX paths. README documents default maximum context of 100 rows and sampled contexts for larger tables. | Defer rather than silently claim every training row enters each context. A larger supported context or deliberate sampling experiment would require its own engineering and validation plan. |
| [Official LimiX repository](https://github.com/limix-ldm-ai/LimiX), [LimiX-2M model card](https://huggingface.co/stable-ai/LimiX-2M), [architecture router](https://github.com/limix-ldm-ai/LimiX/blob/main/inference/predictor.py), [no-retrieval configuration](https://github.com/limix-ldm-ai/LimiX/blob/main/config/reg_default_noretrieval.json) | 2M and 400M are distinct models, both with regression support. Source routes checkpoints by architecture version. Legacy model card installation includes Flash Attention and warns of demanding retrieval hardware. The no-retrieval configuration includes a transform tagged for all-data quantiles. | Defer pending exact version-specific attention and preprocessing inspection. These observations do not prove that every LimiX inference path is T4-incompatible, nor that query labels are used. A model's small parameter count does not settle runtime memory or query-composition behavior. |
| [TabSTAR repository](https://github.com/alanarazi7/TabSTAR), [TabSwift paper](https://arxiv.org/abs/2606.07345) | Regression-oriented research leads; prior V19 source snapshots contain integration detail. | No new feasibility result from reading descriptions. Do not expand V20 after seeing accuracy. |
| [Official Colab FAQ](https://research.google.com/colaboratory/faq.html) | GPU availability, usage limits and runtime duration vary. | Six hours is a campaign ceiling, not a guaranteed allocation. |

Only primary sources support technical recommendations. A general public search also identified copies of the restaurant competition dataset; those were not used to import labels, competitor predictions or evaluation answers. Failed/404 documentation lookups did not establish evidence. The execution lock must resolve sources and checkpoints to immutable identifiers; reading an online `main` branch is not that lock.

## Local primary evidence

- [Fresh audit](evidence_audit.json) and [analysis script](evidence_audit.py): original data/reference hashes, 30 hashed fold outputs including controls, 15 exact metric reconstructions, error concentration, raw marginal covariate diagnostics and predictor-duplicate checks. Run with the bundled Python 3.12 environment containing NumPy/Pandas; no SciPy or model packages are required.
- [V19 screening](../improvement_v19/results/screening.csv), [component diagnostics](../improvement_v19/results/component_diagnostics.csv) and [result](../improvement_v19/delivery/V19_Result_Summary.md): Causilo/TabDPT tested, insufficient improvement.
- [V11 pilot](../improvement_v11/results/pilot.json) and [original model recipe](../improvement_v11/modeling.py): TabICL exclusion occurred on INR 3.814697265625 permutation drift. It did not reach development accuracy testing and had not finished every engineering test.
- [V19 Kumo failure](../improvement_v19/results/pilot_KS8.log), [candidate adapter](../improvement_v19/candidate_models.py): attempted typed categorical tables on CUDA; failure surfaced through the candidate subprocess. The saved parent traceback does not establish the complete internal dependency call chain.
- [Pinned NVIDIA string operations](../improvement_v19/engineering_sources/structured-data-models-2b1696f4fdc22004cc757c44703a69cf326c0a11/sdm/tensor/string.py), especially `_eq`: a documented CPU/Arrow fallback exists when optional cuDF is absent. [Pinned table conversion](../improvement_v19/engineering_sources/structured-data-models-2b1696f4fdc22004cc757c44703a69cf326c0a11/sdm/tensor/table.py) supplies `from_arrow`. These exact implementation files were read locally; this task did not run their GPU path.
- [Existing Kumo checkpoint register](../improvement_v19/checkpoint_registry.json) and [source register](../improvement_v19/research_sources/registry.json): reuse the inspected immutable Kumo source/weight identities; verify actual bytes again at execution. TabICL checkpoint revision and byte hash remain an explicit pre-execution requirement.
- [V13 contract](../improvement_v13/PLAN.md) and [legacy V7 models](../improvement_v19/legacy_models.py): target caps, square-root targets, turnover-band/tier specialists and nested residual models were already explored. Their existence does not prove all data-focused ideas are exhausted.

The local error/correlation findings are measured. The candidate priorities and proposed clean-environment repair are inferences. V20 feasibility, accuracy, resource use and portal improvement are unmeasured.
